# MS2 v3 研究负责人决策摘要

**2026-11-25 · #21 · 协议草案，阶段 A 已执行。** 研究负责人接受 v2 的 `accept_as_insufficient`。17 项 Codex 盲审（4 项正确、13 项无终答）用于 Pilot 辅助评阅和敏感性分析，`human_blind_review` 状态保留。v2 的 8/5/5 实测为 0/0/0，对主要假设暂无可判定结论。保留全部历史结果、失败样本、敏感性分析和来源记录。v3 获准修订，下一轮隔离复验范围获有条件同意，v3 冻结签收和十题复验派发待批。正式确认实验及 MS3 362 题组暂缓。

**当前阻塞与修改。** v2 有 17/30 个空 Checkpoint，内部推理耗尽输出预算。Rater 有效 10/13，Evidence 有效 3/13，Tool-Verified 裁决为 0。v3 只用可见正文作为续推前缀，记录总输出、供应商报告的 reasoning Token、可见正文和结束原因。分别记录空 Checkpoint 的预算耗尽、空成功响应和执行失败，以及续推的固定预算内未完成、判分未知和执行失败。Rater、证据抽取和证据评审使用带示例的 JSON、各自的 schema 和原文定位校验。用 SymPy 或有明确范围的穷举独立核验可判定声明，保存命题、前提、运行结果和反例。其他声明保留 Agent-Assessed 或 Unknown。新运行显式指定 `ms2.protocol_version = "ms2-v3"`，`phase` 仅用于样本隔离，旧协议按冻结记录续跑。

阶段 B 从固定快照按预登记种子 **3103** 抽取无图闭式题，派发前冻结清单并核对原题组和跨库近重复。开发题排除既有 Pilot、复验及留出组，并永久排除出后续隔离复验和确认实验。三题只校准预算与工件覆盖，记录各阶段预算耗尽和每个可判终答的 Token 成本。后续十题继续用 8/5/5 门槛。

**费用记录。** 本轮校准按研究负责人最新指示取消金额门槛。保留方案的请求次数、Token、超时和停止条件。逐笔记录用量、按冻结费率计算的本地估算及可核对的供应商消费。历史 USD 110 硬上限与 USD 19.9904472 保守占用是旧运行记录，继续保留。

**阶段 A 实测。** 两次请求均返回正确可见答案。v2 对照报告 65 个 reasoning Token，显式 `thinking.type="disabled"` 仍报告 30 个且返回推理正文。阶段 A 在第 2 次请求停止，后续 JSON 检查与开发题未派发。合计输入 108、输出 107，其中 reasoning 95。台账估算 USD 0.0001608，供应商实扣待核对。[DeepSeek 推理开关文档](https://api-docs.deepseek.com/guides/thinking_mode/)

**获批范围。** 同一网关按推理开启处理。先用 1 道隔离的 MATH-500 Algebra 4 开发题跑 1 条路线，最多 6 次请求。Checkpoint 上限 4,096，单次续推上限 6,144（两次），Rater、抽取和评审各 4,096，均含推理 Token。检查局部子目标、两次续推状态、三种 JSON 工件与实际工具核验，再决定是否扩至三题。上表阶段 B 是依赖关闭推理的原方案。

**单题实测。** 6 次真实请求均正常结束，输入 1,727、输出 6,023，其中推理 5,149。台账估算 USD 0.0077457，平台实扣待核对。Checkpoint 得到 y=12−3x 与 m=−3，未给出所求终答。两次续推均给出 13；冻结判分器因 LaTeX 行内定界符转盲审。三份评分 JSON 都可解析，Rater 为 2/3，抽取和评审均覆盖两条声明。SymPy 独立核验两条声明并重算终答 13。开发题组已记录为后续排除项。校准在单题结束。

**三题扩展。** 原有两条续推离线重判均为正确，原判分保留。新增两道开发题均取得可见 Checkpoint。MATH-500 两次续推给出 1997/2，第二次因行内定界符与 boxed 嵌套的重复标注仍转盲审。该题一个 Checkpoint 读取超时，两个评分请求收到 HTTP 524。Omni-MATH 的 Checkpoint 上调至 8,192 后获得正文，两次续推、Rater 和证据抽取在各自固定 Token 上限下仍为空。新增两题均无可用评分 JSON，证据评审缺少抽取输入。SymPy 独立核验求和配对恒等式与差平方变形，并重算两题答案。三题共 18 次尝试，15 次有用量，输入 4,144、输出 38,358，供应商报告推理 36,597，部分单次细分超过总输出 1–3 Token。已知用量估算 USD 0.0472728，三次未知用量与平台实扣未归入该估算。十题复验仍待定。
