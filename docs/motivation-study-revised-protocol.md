**冻结与验收。** 按原题组排除既有 Pilot、开发题及跨库近重复。新题组按研究组件分开冻结，预登记版本、固定种子 20261125、抽样与判分规则。对外报告按题组给分母、缺失与区间。公开专家或人工标注标签、工具核验、Agent 判断、新人工盲审各自留源。缺标签、执行失败、未知用量和有效零效应分别报告。验收以隔离、盲化、台账和可复算为准。每个付费对照至少 80% 计划单元可配对评价才做主要比较，否则只报覆盖及原因。复用现有加载、请求与台账、终答判分、盲评和统计，新增工作限于数据映射与研究分析。

**预算与授权。** 建议先批准协议方向及离线资格盘点，当前外部 API **0 次、USD 0**。后续分项申请，合计主体最多 288 次。只有现有模型和执行方式缺乏可迁移证据时，加一次独立最小验证。验证失败停止该路由，下一方案采用经过验证且获准的模型或供应商。评分／诊断每次按输入 8,192、总输出 2,048 Token 预留，修复按 16,384／8,192，验证按 2,048／8,192。全选含验证上界为 **289 次，2,885,632 输入、991,232 总输出 Token**。按历史本地费率 USD 0.30／1.20 每百万估算 **USD 2.055168**，拟议累计新增最高 **USD 2.10**，须在核实实际费率和用量边界后另批。平台实扣与本地估算分记，旧未知用量继续保留。冻结方案及相应分项预算均批准后方可派发。十题旧复验和 MS3 的 362 题组不在范围内。
