# Motivation Study 离线资格与批量授权摘要

**建议有条件批准首批 1 次验证 + 最多 224 次研究请求，新增最高 USD 1.40。** 协议方向及零付费资格盘点已获批。本轮完成本地抽样、盲化和请求冻结草案，新增付费调用 **0**。五项候选共 142 个互不重叠的原题组。按固定种子排除本地已知旧 Pilot、开发和留出题组，并暂扣词法近重复。公开标签、可复算工具证据、Agent 判断和人工标注分开留源。

**冻结配置及可分析门槛。** 首批拟用 AIGCPro `deepseek-v4.1-flash`，沿用非流式 JSON，显式开启推理，总输出每次 2,048 Token，超时 135 秒。已冻结三项请求草案和盲化清单。先用一条隔离合成轨迹验证首错 JSON，要求有可见正文、正确索引、正常结束、完整用量，且报告的推理 Token 不超过总输出。仅发送一次，无自动重试。实测中缺正文、超时、用量未知或越预留即暂停核对。各付费对照至少 **26/32** 个计划原题组可配对分析，按来源和类别分别报告覆盖率。低于 80% 只报覆盖与缺失，零效应和负向结果可报告。

**计价与审批边界。** 历史 v3 的 8 次 Rater 中 3 次有正文，3 次额度耗尽且为空，2 次无用量回执。还出现过输出超过请求值、推理细分超过总输出。历史平台消费截图可核对 12 笔合计 **CNY 0.0015980**，当时显示标准价 CNY 2/8 每百万与 0.075 倍折扣。当前账户有效费率、全量实扣与失败收费仍待确认。225 次名义上限为 1,837,056 输入和 460,800 总输出 Token。计费按每次另预留 1,024 输出 Token，共预留 691,200 输出 Token，按历史本地费率合计 **USD 1.3805568**，其中验证 **USD 0.0043008**。这笔预留是本地估算。核实当前收费及可执行的 **USD 1.40** 支出约束后才允许首发，验证通过才放行三个冻结分项。所有发送和未知收费均占预算，重试须纳入同一上限。本批授权范围不含 MS3-B、旧十题复验和 362 题组。

**解释边界。** MS2-B 回答前缀评分与历史终答成功的关系。MS1 的依赖标注用于描述错误传播与复用机会。后续付费环节完成后才有评分、首错和效应结论。数据来源：[ProcessBench](https://huggingface.co/datasets/Qwen/ProcessBench/tree/3bdcd5371ed567559a78f559c01c13a6deee7604) · [PRM800K](https://github.com/openai/prm800k/tree/7ecc794703b2877f63226f2477a49b34f9b25163)。
